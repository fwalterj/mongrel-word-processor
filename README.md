# Mongrel Word Processor

A native macOS word processor — part of the [Mongrel](https://github.com/mongrel-suite) app suite.

## Overview

Mongrel Word Processor is a fast, native document editor built with TextKit 2. Premium ominous-glass UI with a focus on distraction-free writing and lightweight document formats.

## Stack

- **Language:** Swift
- **Text engine:** TextKit 2 (UsingTextKit2ToInteractWithText reference)
- **Platform:** macOS

## Status

Early development — TextKit 2 research complete, app not yet started.
